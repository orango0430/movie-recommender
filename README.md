# KMDb 영화 추천 (로컬 예제)

한국영상자료원 KMDb API로 영화 줄거리를 모아 TF-IDF + 코사인 유사도로 추천한다. 서버·DB 없이 터미널에서 실행한다.

## 실행

```powershell
py -3.13 -m venv .venv; .venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env                       # KMDB_API_KEY 채우기 (kmdb.or.kr에서 발급)
python collect_kmdb.py --sample              # 응답 구조 확인 -> data/raw/sample.json
python collect_kmdb.py --from 20150101 --to 20251231   # 17번 호출, 약 7,500편 -> data/movies.csv
python recommender.py --similar 기생충
python recommender.py --watched "기생충,올드보이"
python recommender.py --text "복수를 다룬 스릴러"
```

샘플 35편 버전: `python recommender.py --data data/sample_movies.csv --similar 기생충`

`data/movies.csv`(KMDb API 수집본)는 저장소에 넣지 않는다. KMDb 이용약관의 재배포 조건을 확인하기 전이라,
키를 받아 위 명령으로 직접 만든다. 키 없이 보려면 공공데이터포털 CSV로 만든 `data/movies_kmdb_csv.csv`를 쓴다.

### 검색 화면 (로컬)

```powershell
python web.py        # http://localhost:8501
```

추가 설치 없이 파이썬 내장 웹서버로 띄운다. 문장 검색과 비슷한 영화(제목 자동완성)를 고를 수 있고,
결과 카드의 "이 영화와 비슷한 영화"로 이어서 탐색한다. `data/` 폴더에 있는 데이터(API 수집본, 독립영화 CSV, 샘플 35편) 중에서 고른다.

## 추천 방식

문서 = 줄거리 일반명사·동사·형용사(kiwipiepy, 고유명사·인물 이름 제외) + `장르:` 토큰 x2 + `키워드:` 토큰 x2(출처·수상 같은 메타 키워드 제외) + `감독:` 토큰 x1.
영화가 200편 이상이면 `max_df=0.5`(절반 넘게 나오는 단어 제외), `min_df=2`(한 영화에만 나오는 단어 제외).
추천 이유 = 두 영화 TF-IDF 벡터에서 곱이 큰 단어.

## 정제 규칙

HTML 태그·검색 강조 문자열(!HS, !HE) 제거 → 한국어 줄거리만 → 50자 미만 제외 → docid 중복·제목+연도 중복(재개봉) 제거 → 장르 구분자 `|`, 빈 장르는 기타 → 에로 장르 제외 → 1,000편 초과이고 관객 수가 절반 이상 채워져 있으면 관객 수 순 1,000편.

## 결과 점검

### 1차: 공공데이터포털 CSV (KMDb API 키 승인 전)

KMDb API 키가 승인 전이라(`인증키가 필요합니다`), 키 없이 받을 수 있는
[한국영상자료원_영화상세정보](https://www.data.go.kr/data/15109019/fileData.do) CSV(2022-11)로 먼저 돌렸다.

```powershell
python collect_kmdb.py --from-csv data/raw/kmdb_detail   # -> data/movies_kmdb_csv.csv
python recommender.py --data data/movies_kmdb_csv.csv --similar "보이스 (2021)"
```

수집 4,727 → 줄거리 50자 이상 4,006 → 중복 제거 3,991 → 최종 3,991편. 단편 3,489 · 장편 332 · 중편 158, 99%가 국내 독립영화라
기획서 점검 영화(기생충, 범죄도시 등)가 없다. 그래서 이 데이터 안에서 장르가 다른 5편으로 점검표를 바꿨다.
기준: 상위 5개 중 3개 이상 납득되면 통과.

| 점검 영화 | 상위 추천 (이유) | 판정 |
|---|---|---|
| 보이스 (2021) 범죄 | 강릉, 황천, 브라더 (조직·범죄·잠입), 트러스트 미 (보이스피싱) | ✅ 4/5 |
| 브로커 (2022) 가족 | BATTLE BABY, My son, 꿈을 여행, The Son of a River (아기·보육원·부모) | ✅ 4/5 |
| 이 안에 외계인이 있다 (2019) 코미디·SF | 에일리언즈, 딜리버리, 어쩌다 옥탑방 … (외계인·SF) | ✅ 5/5 |
| 22 (2015) 인권·역사 다큐 | 우리 엄마 (위안부·일본군), 할머니 인물 다큐 | ✅ 3~4/5 |
| 휴게소 (2016) 공포 | 여행·노숙자 영화 | ❌ 1/5 |

**4/5 통과.** 휴게소는 줄거리가 가족 여행 중 휴게소라는 배경 위주이고, 공포를 말해 주는 키워드(공포영화, 살인사건)가
다른 영화에 거의 없어 `min_df=2`에 걸러졌다. 장르 가중치를 올리면 나아질 수 있지만 기획서대로 유지했다.

**조정 기록**
- 처음엔 고유명사도 썼는데 브로커·휴게소가 **등장인물 이름**(소영, 경수)으로 엉뚱한 영화와 이어졌다.
  단편은 줄거리가 짧아 이름 하나가 유사도를 좌우한다 → 고유명사(NNP) 제외. 지명·주제어는 키워드 토큰으로 따로 들어간다.
  이 조정으로 브로커가 2/5 → 4/5, 전체 3/5 → 4/5.
- 추천 이유에 자주 보인 무의미한 말(특별, 과정, 지나다, 보이다 …)을 불용어에 추가.

**문장 검색**

| 검색어 | 상위 결과 |
|---|---|
| 복수를 다룬 스릴러 | 초대, TwiT(복수), 누군가 있다, 숲의 비명 |
| 엄마와 딸의 화해 | 한장 차이, 화해, 힘, 애물단지 딸 |
| 청년 취업과 가난 | 정오의 협주곡, 캔커피 인생, 성남에 살면?, 쪽방(가난) |

### 2차: KMDb API (2015~2025 극영화·애니메이션)

2026-10-26 키 승인 후 수집. 극영화 6,873 + 애니메이션 1,026편, 17번 호출, 원본 109MB.

수집 7,899 → 줄거리 50자 이상 7,657 → 중복 제거 7,648 → 에로 장르 제외 7,456 → 최종 7,456편.
관객 수(`audiAcc`)가 6편에만 있어서 "관객 수 상위 1,000편" 자르기는 기획서 규칙대로 건너뛰었다.
한국 1,805 · 미국 1,651 · 일본 924편, 키워드 있는 영화 2,967편, 단어 14,597개.

**점검 영화 교체:** 인터스텔라(2014)와 겨울왕국(2014 국내 개봉)은 수집 범위(2015~2025 개봉) 밖이라 데이터에 없다.
같은 확인 목적의 범위 안 영화로 바꿨다. 인터스텔라 → **마션**(우주 SF, 해외 영화 수집 확인), 겨울왕국 → **겨울왕국 2**(애니메이션 수집 확인).

| 점검 영화 | 상위 추천 (이유) | 판정 |
|---|---|---|
| 범죄도시 (2017) | 나쁜 녀석들: 더 무비, 더 킹, 악인전, 혈랑, 요코하마 갱스터 (조직폭력배·조폭·강력반형사) | ✅ 5/5 |
| 극한직업 (2018) | 무뢰한, 사도행자 2, 치외법권, 나쁜 녀석들: 포에버 (잠복근무·위장경찰·형사·마약단속반) | ✅ 4/5 |
| 마션 (2015) | 프로스펙트, 세르지오 앤 세르게이, 아이스브레이커, 솔리스 (우주탐사·NASA·낙오/고립) | ✅ 4/5 |
| 겨울왕국 2 (2019) | 위시(같은 감독), 알라딘, 엔칸토, 위키드 (디즈니·뮤지컬·마법·왕국) | ✅ 5/5 |
| 기생충 (2019) | 몬태나(인디언), 해피뻐스데이(생일파티), 왓칭·더 서클·더 렌탈(CCTV) | ❌ 1~2/5 |

**4/5 통과.** 기생충의 KMDb 키워드는 인디언, CCTV, 생일파티, 모스부호, 냄새, 수석처럼 **줄거리 속 소품**이 많다.
드문 단어라 TF-IDF 점수가 높고 키워드 2배 가중치까지 붙어 주제(가족, 빈부격차)를 덮는다.
기획서가 기대한 "같은 감독(봉준호) 작품 상위"도 나오지 않았다. 감독 가중치 1로는 줄거리 차이를 넘지 못한다.

**조정 기록 (2차)**
- **인물 이름 제거:** KMDb 줄거리는 `기택(송강호)`처럼 이름(배우) 형식이다. "기우"처럼 일반명사로 분석되는 이름이 남아서,
  괄호 앞 단어와 짧은 따옴표 안 단어를 형태소 분석 전에 지웠다. 범죄도시 5위의 엉뚱한 영화가 사라졌다.
- **메타 키워드 제외:** 실화바탕(216편), 소설원작(152편), 시리즈, 극장판, 리메이크, 황금종려상처럼 내용이 아닌 출처·이력 키워드를 추천 재료에서 뺐다.
  원칙적으로 맞는 처리지만 기생충은 나아지지 않았다("황금종려상"으로 이어지던 어느 가족이 빠지고 CCTV가 남음).
- **문장 검색 불용어:** "~를 다룬", "~를 그린"의 다루다·그리다를 뺐다.
- **키워드 가중치 1 실험 (채택 안 함):** 기생충은 가족 드라마 쪽으로 나아지고 극한직업도 위장수사 영화가 늘었지만,
  마션이 "화성"만 겹치는 영화로, 범죄도시가 줄거리 단어("나쁘다")로 흔들렸다. 기획서대로 2를 유지했다.

**샘플 35편과 비교 (상위 3개)**

| 기준 영화 | 35편 | 7,456편 |
|---|---|---|
| 범죄도시 | 신세계, 범죄도시2, 극한직업 (조직·형사) | 나쁜 녀석들, 더 킹, 악인전 (조직폭력배·강력반형사) |
| 극한직업 | 신세계, 범죄도시, 범죄도시2 (조직·형사) | 무뢰한, 사도행자 2, 치외법권 (잠복근무·위장경찰) |
| 마션 | 인터스텔라, 어벤져스: 엔드게임, 그래비티 (장르 SF) | 프로스펙트, 세르지오 앤 세르게이, 아이스브레이커 (우주탐사·NASA·고립) |
| 겨울왕국 2 | 겨울왕국, 주토피아, 코코 (장르 애니메이션·가족) | 위시, 알라딘, 엔칸토 (디즈니·뮤지컬) |
| 기생충 | 괴물, 마더, 과속스캔들 (가족·딸) | 몬태나, 해피뻐스데이, 왓칭 (소품 키워드) |

- **늘어난 효과:** 35편에서는 고를 영화가 적어 대부분 **장르**가 이유였다. 7,456편에서는 잠복근무, 위장경찰, 우주탐사, 낙오/고립처럼
  **구체적인 주제**로 이어진다. 극한직업은 "조직 범죄 영화"에서 "위장·잠복 수사 영화"로 더 정확해졌다.
- **잃은 것:** 유명작끼리 묶이던 35편과 달리 낯선 영화가 상위에 많다. 유사도만 보고 인기를 모르기 때문이다(다음 단계: 인기 가중치).
- **기생충은 35편이 더 낫다.** 35편에는 키워드가 없어 줄거리의 가족·딸로 이어졌다. 키워드가 오히려 방해한 사례다.
